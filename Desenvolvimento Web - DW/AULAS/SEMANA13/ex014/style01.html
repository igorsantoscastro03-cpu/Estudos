Usando CSS Inline

O estilo mais simples a se aplicar é quando usamos o parâmetro style em qualquer tag do html.

Esse é o método mais simples de todos. É quando o paramêtro style está imbutido na minha tag html.

Este métod,em bora conveniente, ger muitas limitações,pois casos precisemos aplicar em diversas tags a temos que fazer uma por uma (o que dá um trabalho gigantesco)
