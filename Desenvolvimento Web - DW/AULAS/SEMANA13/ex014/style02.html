CSS Interno

Um estilo interno é aquyel eque fica configurado dentro da área do <head> do seu documento.

A grande vantagem desse modelo em relação ao modelo inline é que podemos escrever uma configuração única paratodos os elementos da mesma família. Por exmplo, todos os parágrafos deste documentop estão com a emsma configuração de cor, e eu só preciso escrever isso uma vez.

A grande desvantagem desse modelo em relação à última estrutura que veremos é que no CSS externo (a estrutura do prócimo exercício) é que o estilo não pode ser reaproveitado por outras páginas.

IMPORTANTE: Você pode misturar CSS inline com CSS interno em um mesmo documento sem problemas! Vamos fazer um pequeno TESTE! É desse processo de aplicarmos os estilos em diferentes níveis que surge os conceitos de "Folhas de estilo em cascata".
